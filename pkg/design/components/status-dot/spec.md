# Status dot
Project state at a glance: blue needs you, gray waiting, hollow closed, dots working. A label is plain secondary text beside the dot, or the text alone. No status pills (Apple HIG).

Matched iMessage typing bubble for working; Mail-style unread dot for needs you; Finder/Mail status as dot + secondary text (subheadline, text-2), no capsule.
