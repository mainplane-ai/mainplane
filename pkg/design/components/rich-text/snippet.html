What does a batch of croissants cost?

Croissant batch

One batch makes 48 croissants and costs $34. The shop lists each one with the code CR-48, so it shows on the menu page. The recipe is in the shared folder.

What it needs

  • Flour: a 25 kg bag lasts four batches
  • Butter and eggs: bought each Monday
    • Kept cold for 3 days

With ci the cost of item i in one batch, the week costs

week=b∑i=1nci,b=bMon+bWed+bSat

which is about $204 for b=6.

Python
# What one batch of croissants costs
batch = {"flour": 12, "butter": 18, "eggs": 4}
total = sum(batch.values())  # 34

def weekly(cost, batches=6):
    return cost * batches

print(f"${weekly(total):,.0f} a week")
