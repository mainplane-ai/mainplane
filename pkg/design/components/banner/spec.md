# Banner and status text
No toasts. Status stays where it belongs.

Apple has no toasts on macOS; status sits inline (Mail, Messages "Delivered").

## CSS notes
.status-line: inline banner in the content (info / success / warning / danger) with icon, text, optional action and close.
.status-text: one quiet line (e.g. under the composer: "Sent. The orchestrator is reading it.") with a leading icon or spinner.
