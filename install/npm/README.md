# mainplane

The open-source agent ecosystem. Agents that work across all your computers, browsers and files.

This package runs the `mainplane` CLI. Its first run downloads the release binary for your machine from dl.mainplane.ai, checks it against the release's SHA256SUMS, and caches it.

```
npx mainplane --help
```

To set up a harness, see https://github.com/mainplane-ai/mainplane.
